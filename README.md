# Antigravity Client (Releases)

Официальный публичный репозиторий релизов **Antigravity Client**.

В этом репозитории публикуются готовые кроссплатформенные сборки и инсталляторы (Windows, macOS, Linux), а также работает система автоматических обновлений.

---

Перейдите на страницу **[Релизы (Releases)](https://github.com/gangsecret/AGClientPublic/releases)**, чтобы скачать установщик для вашей операционной системы:

  - `Antigravity Client_1.0.35_x64-setup.exe` (NSIS установщик)

  - `Antigravity Client_1.0.35_x64.dmg` (Intel)
  - `Antigravity Client_1.0.35_aarch64.dmg` (Apple Silicon)

## 🔄 Система автообновлений
Клиент автоматически проверяет наличие новых версий через менеджер и обновляется при выходе релиза.
